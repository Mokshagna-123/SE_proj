# Digital Personal Data Protection Act, 2023
Source ID: MEITY-DPDP-2023
Jurisdiction: India
Version: Act published August 11, 2023; commencement is provision-specific
Source URL: https://www.meity.gov.in/static/uploads/2024/02/Digital-Personal-Data-Protection-Act-2023.pdf

The DPDP Act provides a framework for processing digital personal data for lawful purposes while recognising individuals’ data-protection rights. Determine provision commencement, applicable rules, role and lawful basis for the system under review.
